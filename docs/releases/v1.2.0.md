# Psst 1.2.0 — Bloqueo continuo de audio

Esta versión convierte el modo biblioteca en una protección persistente durante toda la sesión.

## Novedades

- Mantiene volumen cero y mute activo aunque otra app o el usuario intenten modificarlos.
- Detecta actividad genérica de la salida y muestra un aviso para recordar que Psst continúa activo.
- Conserva el estado previo y lo restaura al desactivar el modo.
- Incorpora de forma segura una salida compatible conectada durante la sesión.

## Privacidad y seguridad

La detección se realiza con propiedades públicas de Core Audio. Psst no captura muestras de audio, no identifica Spotify, el navegador ni ninguna otra app y no conserva un historial. App Sandbox sigue activo con un único entitlement y sin red, micrófono, Apple Events, procesos auxiliares o privilegios de administrador.

Psst bloquea la salida sonora; no pausa el motor de reproducción de otras apps. Los dispositivos externos que no expongan volumen o mute por software pueden no admitir el bloqueo.

## Descarga

`Psst-1.2.0-macOS-universal.zip` contiene la app para Apple Silicon e Intel. La compilación de GitHub usa firma ad hoc. La distribución oficial fuera de GitHub todavía requiere Developer ID o Apple Distribution, notarización cuando corresponda y, para Mac App Store, la revisión de Apple.
