# Psst 1.0.0

Primera versión pública de Psst, el modo biblioteca seguro y reversible para macOS.

## Incluye

- Silenciado de audio y alertas con un solo botón.
- Ajustes energéticos para reducir actividad, calor y ruido potencial.
- Restauración del estado anterior al terminar.
- Integración opcional con No molestar mediante Atajos.
- App universal compatible con Apple Silicon e Intel.

## Instalación

Descarga el archivo ZIP, descomprímelo y mueve `Psst.app` a la carpeta Aplicaciones. Esta versión utiliza firma ad hoc; si macOS muestra un aviso, haz clic derecho en la app y elige **Abrir**.

Psst no fuerza la velocidad de los ventiladores ni desactiva las protecciones térmicas del Mac.
