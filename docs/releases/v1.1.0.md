# Psst 1.1.0 — Compacta, translúcida y aislada

Esta versión rediseña Psst como una pequeña utilidad de escritorio para estudiantes, opositores y personas que trabajan en bibliotecas o espacios compartidos.

## Novedades

- Ventana prácticamente cuadrada de 468 × 500 puntos, sin scroll.
- Apariencia glassmorphism nativa con `NSVisualEffectView` y materiales de SwiftUI.
- Acceso permanente desde la barra de menús.
- Silenciado y restauración reversible mediante la API pública Core Audio.
- Automatizaciones opcionales iniciadas por el usuario con Apple Atajos.
- App Sandbox activo con un único entitlement y Hardened Runtime.
- Sin red, acceso a documentos, Apple Events, contraseña de administrador ni procesos auxiliares.

## Seguridad térmica

Psst no intenta modificar directamente los ventiladores. macOS conserva el control térmico del equipo; la reducción de calor se deja a las acciones oficiales de Bajo consumo que el usuario decida añadir a sus atajos.

## Descarga

`Psst-1.1.0-macOS-universal.zip` contiene una app universal para Apple Silicon e Intel. La compilación publicada en GitHub usa firma ad hoc; para una distribución fuera de GitHub o en Mac App Store todavía se necesitan un certificado Developer ID o Apple Distribution, notarización cuando corresponda y revisión de Apple.
