# Psst 1.3.0 — Ultra Focus (Hard Mode)

Esta versión convierte el bloqueo continuo de audio en un modo claramente identificable y controlado por el usuario.

## Novedades

- Nuevo interruptor **Ultra Focus (Hard Mode)** en la ventana principal.
- El modo normal silencia el Mac una vez y restaura el estado al terminar.
- Ultra Focus comprueba el audio cada 400 ms, corrige intentos de recuperar volumen o mute y muestra un aviso.
- El selector queda bloqueado durante una sesión para mantener un comportamiento predecible.
- Textos, privacidad, seguridad y arquitectura actualizados.

## Seguridad y límites

Psst continúa dentro de App Sandbox y usa únicamente Core Audio público. No captura sonido, no identifica aplicaciones y no controla la reproducción de Spotify, navegadores o reproductores de vídeo. Las salidas sin controles de volumen o mute por software pueden quedar fuera de su alcance.
