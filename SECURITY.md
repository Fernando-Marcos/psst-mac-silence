# Política de seguridad

## Versiones compatibles

La versión estable más reciente recibe correcciones de seguridad.

## Comunicar una vulnerabilidad

No publiques contraseñas, datos personales ni detalles explotables en una incidencia pública. Utiliza la opción **Report a vulnerability** de la pestaña Security del repositorio para enviar un informe privado.

Incluye la versión de macOS, el modelo de Mac, la versión de Psst, los pasos para reproducir el problema y su posible impacto. Recibirás una confirmación cuando el informe haya sido revisado.

## Modelo de seguridad

Psst no instala extensiones de kernel, no modifica directamente el SMC y no fuerza la velocidad de los ventiladores. Los cambios privilegiados se realizan mediante herramientas incluidas en macOS y el diálogo de autorización del sistema.
